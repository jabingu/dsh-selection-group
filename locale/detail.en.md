Select text in the main conversation and release the mouse to open the toolbar. You can select across messages.

Side chat requires Better Sidebar. The selected text goes into a new thread’s draft for you to send when ready.

**Disable DSH built-in quote** is on by default. Turn it off under **Quote settings** on this page to restore DSH’s built-in quote button.
